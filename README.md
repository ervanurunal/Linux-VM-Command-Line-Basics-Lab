# Linux VM & Command-Line Basics Lab

## Overview

This project documents a hands-on Linux virtual machine and command-line exercise completed as part of my IT Support Specialist training.

The lab introduced the Qwiklabs hands-on learning environment and provided practical experience accessing a Linux virtual machine through a shell and creating a directory using the command line.

The exercise focused on accessing a Linux environment, understanding the command-line interface (CLI), using basic Linux commands, and performing a simple file-system operation.

The objectives of this lab were to:

# Lab Walkthrough

## Step 1 — Start the Lab

I started the hands-on lab environment by selecting the **Start Lab** button.

After the lab started, I was provided access to a Linux virtual machine.

The virtual machine provided a shell where I could interact with the Linux operating system using command-line commands.

---

## Step 2 — Open the Linux Shell

After starting the lab, the Linux shell became available.

![Open the Linux Shell](https://i.imgur.com/lAUHP1D.png)

---

## Step 3 - Enter the mkdir Command

I entered the following command into the Linux terminal:

mkdir my-super-cool-folder

![enter the mkdir command](https://i.imgur.com/H1cxmVF.png)

**The mkdir command is used to create a new directory.**

---

## Step 4 - Create the Directory

After entering the command and pressing Enter, the Linux system processed the command.

The requested directory was created in the current working directory.

The directory created was: **my-super-cool-folder**

This demonstrated how a basic Linux command can be used to perform a file-system operation.

---

## Result

A directory named **my-super-cool-folder** was created.

## Cybersecurity Relevance

Linux and command-line skills are important foundations for cybersecurity.

SOC Analysts and other cybersecurity professionals may interact with Linux systems when investigating security alerts, analyzing systems, reviewing files, examining logs, and performing incident-response activities.

**Basic Linux command-line knowledge can be useful for:**

- Investigating suspicious files
- Navigating directories
- Reviewing system information
- Examining logs
- Checking file permissions
- Investigating compromised systems
- Running security tools
- Supporting incident-response activities
- Performing system troubleshooting

For example, during a security investigation, an analyst may need to navigate directories, inspect files, review logs, or execute security-related commands from a Linux terminal.

This lab provided foundational experience with the Linux command line that can be expanded into more advanced cybersecurity tasks.
